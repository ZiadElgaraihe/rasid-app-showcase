# RASID – Real-Time Facility Management App

## 📱 Overview
RASID is a production-grade facility management mobile application built using Flutter.  
It was designed to support real-time monitoring, reporting, and communication across facility operations, with a focus on performance, scalability, and reliability.

## 🚀 Key Features
- SOS emergency alert system for critical situations  
- Automated reporting and task tracking  
- Staff registration and management flows  
- Real-time notifications using Firebase Cloud Messaging  
- OCR-based ID data extraction to reduce manual input  
- Organized modules for daily operations and communication
- Built-in walkie-talkie style communication for real-time coordination  

## 🛠 Tech Stack
- Flutter & Dart  
- Clean Architecture  
- BLoC (State Management)  
- REST APIs (Dio)  
- Firebase (FCM)  
- Hive & Secure Storage
